\*\*Trouble\*\*

Trouble is a race game in the Parcheesi family for 2 to 4 players. Each player moves a set of tokens out of Home, once around a shared track, and up a private finish lane. Land on an opponent's token and you send it back to its Home. The first player to bring every token to the finish wins.

\*\*The Board\*\*

The shared track has 28 spaces unless the host picks another size. Track spaces are numbered the same way for everyone, from 1 up to the track size, and tokens move toward higher numbers, wrapping from the last space back to space 1.

Each player has a start space on the track. The first player's start space is space 1, and in seating order each of the others lies further on by the track size divided by the number of players, rounded down. With 4 players on 28 spaces, the start spaces are 1, 8, 15 and 22.

A token goes once around the track, from its start space to the space just before it, then turns into its owner's private finish lane of 4 spaces. One step past the end of the lane is the finish.

\*\*Your Turn\*\*

Players take turns in seating order, starting with the first player seated. At the start of every turn, each player hears a short summary: how many of their own tokens are in Home, on the track and finished, and the same for each other player. Tokens in a finish lane count as on the track.

1\. \*\*Pop the die:\*\* Roll a number from 1 to 6.

2\. \*\*Move a token:\*\* If no token can move, your turn passes. If only one token can move, the game moves it for you. Otherwise, choose which token to move with the number keys or the token list, which reads where each token is.

\*\*Moving\*\*

\* \*\*Leaving Home:\*\* A token in Home needs a 6 to come out, unless the host has turned that rule off, in which case any roll releases it. A released token goes onto your start space, whatever number you rolled.

\* \*\*On the track:\*\* A token moves forward the number rolled. Your own tokens may share a space.

\* \*\*Bumping:\*\* If your token lands on a track space holding an opponent's token, that token goes back to its owner's Home; if several opponent tokens share the space, only one of them goes back. This also happens when you release a token onto a start space where an opponent's token sits. Tokens on safe spaces can't be bumped, and nothing can be bumped inside a finish lane.

\* \*\*Finishing:\*\* By default, a token needs the exact roll to reach the finish, and a roll that would carry it past can't be used for that token. The host can change this with the Finish option.

\* \*\*Rolling a 6:\*\* By default, a 6 earns another turn after your move, even when no token could move. There is no limit on how many 6s in a row you can roll.

\*\*Winning\*\*

The first player with all of their tokens at the finish wins.

In team mode, the players form two teams, and a team wins when every one of its players has all their tokens at the finish. The mode is made for 4 players: with 4, the host can review the teams and swap players between them before the game starts. The game also starts with fewer players, splitting them between the two teams in turn. A teammate's tokens can still be bumped like anyone else's. A player who gets all their tokens home first keeps taking turns, but has nothing left to move.

\*\*Customizable Options\*\*

\* \*\*Preset:\*\* A name for a set of rules (default Classic Hasbro; choices Custom, Classic Hasbro, Fast and Brutal). Choosing a preset changes only this setting: it doesn't change the options below, and changing them doesn't change it, so set each option yourself.

\* \*\*Team mode:\*\* Individual, or 2 teams of 2 (default Individual).

\* \*\*Track size:\*\* Number of spaces on the shared track (default 28; choices 20, 24, 28, 32, 36 or 40).

\* \*\*Tokens per player:\*\* How many tokens each player races home (default 4, choices 2 to 6).

\* \*\*Extra turn on rolling a 6:\*\* Whether a 6 earns another turn (default on).

\* \*\*Require 6 to leave Home:\*\* When off, any roll releases a token (default on).

\* \*\*Safe spaces:\*\* Spaces where tokens can't be bumped (default None). \*\*Home stretch only\*\* makes the space just before each start space safe, which is the last track space before that player's finish lane; with 4 players on 28 spaces, those are spaces 7, 14, 21 and 28. \*\*Every 7th space\*\* makes spaces 1, 8, 15, 22 and so on safe, counting from space 1.

\* \*\*Finish:\*\* What happens when a roll would carry a token past the finish (default Exact roll required). With \*\*Exact roll required\*\*, that token can't use the roll. With \*\*Overshoot bounces back\*\*, the token reaches the finish and moves back the extra steps; if that would take it back out of the finish lane, it can't use the roll. With \*\*Overshoot allowed\*\*, the token finishes anyway.

\* \*\*Bot difficulty:\*\* How built-in bots choose their moves (default Greedy; choices Naive or Greedy). Naive bots pick any legal move at random. Greedy bots prefer bumping an opponent, then finishing a token, then entering the finish lane, then leaving Home.

\*\*Keyboard Shortcuts\*\*

\* \*\*R:\*\* Pop the die.

\* \*\*1-6:\*\* Move that token, up to the number of tokens you have.

\* \*\*E:\*\* Check the board: where each of your tokens is, then every other player's tokens.

\* \*\*T:\*\* Check whose turn it is.

\*\*Strategy\*\*

\* Count the spaces between your tokens and the enemy tokens behind them. A token 1 to 6 spaces ahead of an enemy token is within reach of its next roll, unless your token is on a safe space or the enemy token turns off into its finish lane first.

\* With several tokens out, you have more choices on each roll, which makes it easier to bump or to dodge.

\* An enemy start space is dangerous ground: unless it is a safe space, a token sitting there is bumped when that player releases a token.
